# São Bento Dobrões Personalizados

Loja de dobrões personalizados e acessórios. Mantém o layout, os temas claro/escuro, catálogo, filtros, carrinho, frete, checkout e administração da base original.

## Executar

```sh
npm ci
npm start
npm test
```

Requer Node 24 ou superior. Configure um ambiente próprio a partir de `.env.example`; não reutilize o banco de pedidos da outra loja. Pagamentos ficam desativados até configurar as credenciais, frete e identificação do vendedor. Imagens do catálogo são ilustrativas e os preços de R$ 150 foram preservados da base.
